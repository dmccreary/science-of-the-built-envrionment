# About

An interactive intelligent textbook on the science of the built environment: how buildings, materials, energy, air, light, and sound shape human health, comfort, and sustainability.

## Audience

This book is written for college undergraduates in construction, architecture, and building-systems programs, including future electrical designers. It was developed for students at Dunwoody College of Technology in Minneapolis, Minnesota, so its examples emphasize cold-climate construction.

The only prerequisite is a high-school education. Basic high-school algebra and geometry are helpful. After working through the book, you should be able to read a set of drawings, trace how loads, heat, air, and moisture move through a building, compare materials by performance, cost, and environmental impact, apply code requirements, and talk with the specialists who design and build each system. See the [Course Description](course-description.md) for the full list of learning outcomes.

## How to Use This Book

- Read chapters in order — concepts are introduced in dependency order.
- Use the search bar (top right) to jump to a specific term.
- Try the MicroSims as you encounter them; they are the fastest way to build
  intuition for a new concept.
- Check the [Learning Graph](learning-graph/index.md) when you want to see how
  a concept fits into the larger picture.
