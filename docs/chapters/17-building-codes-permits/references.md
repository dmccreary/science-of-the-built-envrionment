# References: Building Codes, Permits, and Enforcement

1. [Building code](https://en.wikipedia.org/wiki/Building_code) - Wikipedia - Defines building codes, their purposes, the difference between prescriptive and performance requirements, and their history in several countries. It frames this chapter's opening on codes as enforceable minimums, with a section on criticisms.

2. [International Code Council](https://en.wikipedia.org/wiki/International_Code_Council) - Wikipedia - Covers the organization that publishes the International Building Code and the other I-Codes, including its consensus process and how states adopt its model codes. It supports the chapter's model-code and adoption discussion.

3. [Zoning](https://en.wikipedia.org/wiki/Zoning) - Wikipedia - Explains how districts control permitted uses, height, lot coverage, and setbacks, with history and a comparison of approaches. It supports the chapter's distinction between zoning ("may we build here?") and the building code.

4. Building Codes Illustrated: A Guide to Understanding the International Building Code (Latest Edition) - Francis D. K. Ching and Steven R. Winkel - Wiley - Ching's diagrams turn dense code text on occupancy, height and area, and egress into annotated drawings. It models this chapter's use-factor-load-exits chain visually.

5. Fundamentals of Building Construction: Materials and Methods (Latest Edition) - Edward Allen and Joseph Iano - Wiley - Opens with a clear, illustrated explanation of how codes, construction types, and permits shape a project. It is most praised for clarity, and it complements this chapter's overview of enforcement.

6. [Overview of the Minnesota State Building Code](https://www.dli.mn.gov/business/codes-and-laws/overview-minnesota-state-building-code) - Minnesota Department of Labor and Industry - Describes the six-year adoption cycle for Minnesota building codes, with links to current code editions, the makeup of the code, and state snow load and frost depth maps for designers.

7. [Minnesota](https://www.iccsafe.org/advocacy/adoptions-map/minnesota/) - International Code Council - Summarizes how Minnesota adopts ICC codes, the roles of the State Building Official and State Fire Marshal, and the 2015 law limiting updates to every six years. It illustrates the chapter's model-code adoption chain.

8. [Building Code Plan Review](https://www.minneapolismn.gov/business-services/licenses-permits-inspections/construction-permits/building-safety/plan-review/) - City of Minneapolis - Explains how Minneapolis plan reviewers examine construction documents against the Minnesota State Building Code before a permit is issued, and links to phased-permit and commercial review guidance.

9. [Certificate of Occupancy](https://www.minneapolismn.gov/business-services/licenses-permits-inspections/construction-permits/building-safety/certificate-of-occupancy/) - City of Minneapolis - States what a certificate of occupancy allows, that all trade inspections and a final inspection must pass first, and when a change of use requires a new one. It grounds the chapter's closing step locally.

10. [Guidance on the 2010 ADA Standards for Accessible Design](https://www.ada.gov/law-and-regs/design-standards/standards-guidance/) - U.S. Department of Justice - Explains the federal accessibility standards for new construction and alterations, including path of travel, assembly areas, and wheelchair spaces. It supports the chapter's point that federal accessibility law applies in addition to the building code.
