## Layout Notes

- The before-and-after pair is the core idea: same house, same weather, same time, different building. Match the positions of the clock, the thermometer, the tree, and the house in both panels so the eye can compare them.
- Use color to carry the temperature story: cold slate and gray-blue on the left, warm yellow and sage green on the right.
- Use the accent color of each panel for its border and for one prominent object inside it.
- Between panels leave a clear cream gap. Do not let drawings, shadows, or glows spill into the gaps.
- The six tiles are equal in size and weight so none looks like the main answer.
